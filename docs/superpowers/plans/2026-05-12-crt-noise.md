# CRT Noise Effect Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an always-on ambient pixel-static overlay that reads as a CRT TV with no signal, with its own independent burst orchestrator.

**Architecture:** Full-page `<canvas id="crt-noise">` element, drawn via 2D context with random white pixels at variable opacity. JS `initCrtNoise()` runs an ambient `setInterval` draw loop and a separate `setTimeout` burst orchestrator — both completely independent of the glitch orchestrator in `orchestrate()`. Guarded by `body.low-fi`.

**Tech Stack:** Vanilla JS, Canvas 2D API, CSS. No dependencies. Pure static site — no build step.

## Task 3: initCrtNoise() — draw loop + burst orchestrator

**Files:**
- Modify: `js/main.js` (add function before `document.addEventListener('DOMContentLoaded', ...)`)

- [ ] **Step 1: Add initCrtNoise() function**

In `js/main.js`, add the following function immediately before the `document.addEventListener('DOMContentLoaded', ...)` line (currently line 301):

```js
function initCrtNoise() {
    const canvas = document.getElementById('crt-noise');
    if (!canvas) return;
    const ctx = canvas.getContext('2d');

    function resizeCanvas() {
        canvas.width = window.innerWidth;
        canvas.height = window.innerHeight;
    }
    resizeCanvas();
    window.addEventListener('resize', resizeCanvas);

    function drawNoise() {
        const density = state.isNoising ? CONFIG.NOISE_DENSITY_BURST : CONFIG.NOISE_DENSITY_AMBIENT;
        const count = Math.floor(canvas.width * canvas.height * density);
        ctx.clearRect(0, 0, canvas.width, canvas.height);
        ctx.fillStyle = '#ffffff';
        for (let i = 0; i < count; i++) {
            ctx.globalAlpha = 0.3 + Math.random() * 0.7;
            ctx.fillRect(
                Math.floor(Math.random() * canvas.width),
                Math.floor(Math.random() * canvas.height),
                1, 1
            );
        }
    }

    state.noiseInterval = setInterval(drawNoise, 1000 / CONFIG.NOISE_FPS_AMBIENT);

    function noiseBurstLoop() {
        if (!state.isNoising && Math.random() < CONFIG.NOISE_BURST_PROBABILITY) {
            state.isNoising = true;
            clearInterval(state.noiseInterval);
            state.noiseInterval = setInterval(drawNoise, 1000 / CONFIG.NOISE_FPS_BURST);
            setTimeout(() => {
                state.isNoising = false;
                clearInterval(state.noiseInterval);
                state.noiseInterval = setInterval(drawNoise, 1000 / CONFIG.NOISE_FPS_AMBIENT);
            }, CONFIG.NOISE_BURST_DURATION);
        }
        const wait = CONFIG.NOISE_BURST_WAIT_MIN +
            Math.random() * (CONFIG.NOISE_BURST_WAIT_MAX - CONFIG.NOISE_BURST_WAIT_MIN);
        setTimeout(noiseBurstLoop, wait);
    }

    noiseBurstLoop();
}
```
