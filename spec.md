# Track Specification: Restore Missing Page Sections

## Overview
This track addresses a bug where the `index.html` page is missing the main header and content area that are present in the other pages of the website. The `index.html` page should have a similar structure to the `demoreel.html` page, with a header, a main content area, and a footer.

## Goals
1.  **Restore Header:** Add the main header to the `index.html` page.
2.  **Restore Content Area:** Add the main content area to the `index.html` page.
3.  **Restore Footer:** Ensure the footer is present and correctly positioned in the `index.html` page.

## Technical Requirements
*   The `index.html` page should be updated to include the same `header`, `main`, and `footer` structure as the `demoreel.html` page.
*   The `hero` section should be moved inside the `main` content area.
*   The navigation links in the header should be updated to reflect the current page.

## Deliverables
*   An updated `index.html` file with the correct page structure.
